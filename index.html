About My Hobby & Process

How I Started

My passion for digital graphic design started from playing mobile football games and admiring custom player cards. I loved how events were visually presented in FC Mobile, which inspired me to create my own unique concepts.

Tools & Apps Used

To craft these designs, I rely on several key platforms and applications: FC Forum for community inspiration and templates, PicsArt for detailed image editing and layering, RenderZ for stats and assets reference, and ChatGPT to brainstorm design ideas and structure content.

Development Note: This website is currently an Alpha Version using browser LocalStorage for data persistence. Full cloud database integration is planned for next month.
